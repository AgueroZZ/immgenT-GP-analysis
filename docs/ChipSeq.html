Rmd 48ba877 Ziang Zhang 2026-11-27 Document ChIP-seq enrichment of gene program signatures

Across 200 ImmGen-T gene programs (GPs), which signatures contain more genes bound by a transcription factor (TF) than expected for genes with similar expression? We tested each ChIP-seq experiment separately, then summarized the results for each TF and GP.

Workflow

Experiments and target genes. We selected 1,303 mouse (mm10) primary T-cell experiments from ChIP-Atlas, covering 143 distinct ChIP targets. We excluded two tag or pulldown labels, two targets with incomplete data and 62 targets classified as cofactors, chromatin regulators or other non-sequence-specific proteins. For each experiment (SRX), we counted a gene once if its ChIP-Atlas score was positive within 5 kb of its transcription start site in either direction. Requiring at least five target genes among the 19,805 genes in the factor matrix left 795 experiments for 77 TFs. ChIP-Atlas target-gene data · ChIP-Atlas publication

GP signatures. We divided each gene loading by the largest absolute loading in its GP. Scores above 0.1 defined the positive signature and scores below −0.1 defined the negative signature. This gave 200 positive and 189 nonempty negative signatures. We excluded the assayed TF’s own gene from each comparison.

Enrichment. We grouped genes into 20 bins by mean expression. Within each bin, the expected overlap equals the number of signature genes times the fraction of genes bound in that experiment. We summed these expectations across bins and divided the observed overlap by that sum to obtain the adjusted fold enrichment. We used a one-sided, expression-stratified hypergeometric test. We applied Benjamini–Hochberg correction separately to the 159,000 positive-signature tests (795 experiments × 200 signatures) and the 150,255 negative-signature tests (795 × 189). Within each direction, an experiment passed for a signature when q < 0.05 and at least five signature genes overlapped its targets. We repeated each analysis with one expression-matched random gene set per signature. Neither control yielded a passing TF–GP pair.

# For one SRX and one GP signature, after excluding the TF's own gene.
# in_signature and bound are logical vectors over the same background genes.
bins <- split(seq_along(in_signature), expression_bin)
expected <- sum(vapply(bins, function(i) {
  sum(in_signature[i]) * mean(bound[i])
}, numeric(1)))
adjusted_fold <- sum(in_signature & bound) / expected
